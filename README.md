## 📌 Descripción

Este proyecto busca **analizar y visualizar datos de salud** para ofrecer insights útiles que apoyen la toma de decisiones en hospitales y servicios de salud.  
Se utilizan técnicas de **ciencia de datos**, análisis estadístico y visualización interactiva para explorar tendencias, patrones y eficiencias.
